1처음 한 번: 설치

가상환경을 만들고 저장소를 편집 가능 모드로 깔면, 코드를 고친 것이 바로 반영된다.

python3 -m venv .venv && source .venv/bin/activate   # miniforge 기본 python에는 usd-core(pxr) 등이 없다
pip install -e ".[dev]"                               # 선택 묶음: .[mpc](casadi), .[slides](python-pptx), .[sim](mujoco)
pytest -q                                             # acados·cupy·CUDA·체크포인트가 없으면 해당 시험은 건너뛴다
  • 셸을 새로 열 때마다 source .venv/bin/activate를 다시 한다. 켰는지는 which python3가 .venv/bin/python3를 찍는지로 본다.
  • pytest -q의 skip은 실패가 아니다. 무엇을 건너뛰었는지는 pytest -rs로 본다.

2체크포인트 받기

학습 Planner 스택은 checkpoints/의 가중치가 있어야 도는데, 이 폴더는 git에 없다. GitHub 릴리스에서 받거나 직접 학습한다.

mkdir -p checkpoints && cd checkpoints
for r in ckpt-2026-09-27 ckpt-2026-10-06; do      # Planner D·LearnedPlanner·Joint Planner·TravNet, 잔차 GP
  gh release download $r -R Geonhee-LEE/travplan --clobber && sha256sum -c SHA256SUMS
done
cd ..
쓰는 스택 필요한 파일 받는 곳
planner_d+…, planner_df+…, planner_dg+… planner_d.pt ckpt-2026-09-27
planner_dd+… planner_d_dagger.pt ckpt-2026-09-27
learned+… waypoint_net.pt ckpt-2026-09-27
joint_planner+… joint_planner.pt ckpt-2026-09-27. 없으면 오류 없이 무작위로 초기화한 망으로 돈다
…+mppi_ccgp, …+mppi_ccgpm, …+mpc_gp, …+mpc_gpcc, …+mpc_gp_sc residual_sgp_wide.pt ckpt-2026-10-06
guidance+mppi 등 나머지 없음

gh가 인증을 물으면 gh auth login부터 한다. 직접 학습하려면 아래 명령을 쓴다.

python scripts/train_planner_d.py --maps 256 --states 128          # Planner D, 시연 수집 3분 + 학습 19분(CPU)
python scripts/train_learned_planner.py --iters 3000 --maps 64    # LearnedPlanner, CPU 약 8분

3벤치마크 한 번 돌리기

벤치마크는 시나리오 × 레벨 × seed마다 같은 지형 위에서 스택을 하나씩 돌리고, 결과를 metrics.csv에 남긴다.

mkdir -p results/eval
python scripts/run_benchmark.py --stacks guidance+mppi planner_d+mppi --seeds 0 1 2 --out results/eval | tee results/eval/bench.log
python scripts/compare_runs.py results/eval results/other --labels base new     # 두 실행을 나란히 본다
바꾸고 싶은 것 플래그
어떤 스택 --stacks Planner+Controller …(예: guidance+mppi, planner_df+mppi)
지형과 난이도 --scenarios curb_ramp …, --levels 0 1 2 3
보행자 --pedestrians 5, 반응형은 --ped-react 0.5
스워브 plant --plant(Controller는 mppi_plant_lag)
GPU --device cuda
같은 지형에서 난수만 바꾸기 --rng-offset 1000

화면에는 에피소드마다 한 줄이 찍히고, 끝에 스택별 집계표가 나온다. 전체 플래그는 python scripts/run_benchmark.py --help로 본다.

4결과 보기

숫자는 metrics.csv와 집계표로, 궤적은 그림이나 GIF로 본다.

python scripts/plot_results.py --results results/eval --seed 0 --out results/eval/trajectories.png
python scripts/visualize_joint_planner.py --scenario bumps_potholes --seed 0 --guidance --out results/viz.gif
파일 내용
metrics.csv 에피소드마다 한 줄. 성공, 실패 유형(lethal, tip, collision, timeout), 도달 시각, 최대 pitch, GT cost, 계획·제어 시간
plan_stats.csv 폴백을 켠 스택(planner_df)이 Guidance 폴백을 제안하고 고른 횟수
traj_<시나리오>_<seed>_<스택>.npy 실행한 궤적(x, y)

plot_results.py는 정해 둔 세 스택(guidance+mppi, learned+tracker, learned+mppi)만 그린다. planner_d+mppi 같은 다른 스택의 궤적은 그리지 않는다. visualize_joint_planner.py는 --guidance가 없으면 무작위로 초기화한 Joint Planner로 달린다.

5바꾼 것을 판정하기

판정은 두 층이다. 재현되는 조건은 숫자 하나의 차이도 보고, 혼돈 조건은 짝 비교로만 본다.

층 조건 판정
1층 스모크 레벨 0, 정적, L0, seed 0–2(12 에피소드) 다시 돌려도 수치가 같다. 숫자가 하나라도 바뀌면 변경이 낸 차이다
2층 짝 비교 레벨 3, plant, 보행자, L1 팔마다 seed 0–9 × 난수 오프셋 셋. 변경 쪽만 성공한 수가 잡음 바닥보다 커야 한다 
python scripts/run_benchmark.py --stacks guidance+mppi planner_d+mppi --seeds 0 1 2 --out results/eval    # 1층
for o in 0 1000 2000; do                                                                                  # 2층
  for s in guidance+mppi planner_df+mppi; do
    python scripts/run_benchmark.py --stacks $s --levels 3 --seeds $(seq 0 9) --rng-offset $o --out results/l3/${s%%+*}_o$o
  done
done
python scripts/paired_success.py --a results/l3/guidance_o{0,1000,2000} --b results/l3/planner_df_o{0,1000,2000}
  • paired_success.py는 에피소드를 시나리오와 seed로 짝짓는다. 그래서 실행 폴더 하나에 스택을 하나만 둔다.
  • 치명 실패가 기준보다 하나라도 늘면 두 층 모두에서 기본값으로 채택하지 않는다.
  • 기준표 전체와 결정 근거는 CLAUDE.md의 '평가 기준'에 있다.

6NMPC 스택

mpc* 스택은 acados 소스 빌드가 필요하고, 라이브러리 경로를 셸에서 먼저 잡아야 한다.

pip install -e ".[mpc]"
export ACADOS_SOURCE_DIR=$HOME/acados
export LD_LIBRARY_PATH=$HOME/acados/lib:$LD_LIBRARY_PATH
pip install -e $ACADOS_SOURCE_DIR/interfaces/acados_template      # acados의 파이썬 인터페이스. 없으면 MPC 시험이 skip된다
python scripts/run_benchmark.py --stacks guidance+mppi guidance+mpc --seeds 0 1 2 --out results/mpc
  • acados 소스 빌드 순서는 docs/research-mpc.md의 M.3.1에 있다.
  • 코드 안에서 바꾼 LD_LIBRARY_PATH는 같은 프로세스에 듣지 않는다. 동적 로더가 프로세스를 시작할 때의 값만 읽기 때문이다.
  • 여러 프로세스를 함께 돌릴 때는 TRAVPLAN_ACADOS_BUILD로 프로세스마다 솔버 생성 폴더를 나눈다.

7L1 인식 루프

L1은 합성 LiDAR를 elevation_mapping_cupy 코어로 지도화하므로, GPU와 cupy가 든 별도 가상환경 .venv-emap에서 돌린다.

python3 -m venv .venv-emap
.venv-emap/bin/pip install cupy-cuda12x numpy scipy torch simple_parsing "ruamel.yaml" opencv-python-headless shapely matplotlib
PYTHONPATH=$PWD:$PYTHONPATH .venv-emap/bin/python scripts/run_benchmark.py --stacks guidance+mppi planner_df+mppi --device cuda \
  --perception l1 --shadow-ceiling --shadow-depth 0.10 --stereo --unknown-near 1.5 --shadow-low-fill --pit-margin 0.05 \
  --seeds 0 1 2 --out results/l1

--perception l1 뒤의 여섯 플래그가 권장 L1 설정이다(TP-0146·0148). 구성은 travplan_ws/src/elevation_mapping_cupy/VENDORED.md에 있다.

8문제 해결

돌지 않으면 대부분 체크포인트, 가상환경, 라이브러리 경로 중 하나가 빠졌다.

증상 원인 확인 해결
checkpoints/planner_d.pt가 없다는 오류 체크포인트를 받지 않았다 ls checkpoints/ 릴리스에서 받는다(2절)
ModuleNotFoundError(markdown, torch 등) .venv를 켜지 않았다 which python3 source .venv/bin/activate
ModuleNotFoundError: cupy L1을 .venv로 돌렸다 명령의 파이썬 경로 .venv-emap/bin/python으로 돌린다(7절)
libqpOASES_e.so를 못 찾는다 셸에 LD_LIBRARY_PATH가 없다 echo $LD_LIBRARY_PATH 셸에서 export한 뒤 다시 돌린다(6절)
MPC 시험이 skip된다 acados_template을 못 찾는다 pytest -rs pip install -e $ACADOS_SOURCE_DIR/interfaces/acados_template로 깐다. PYTHONPATH로 잡았다면 덮어쓰지 말고 앞에 붙인다(PYTHONPATH=$PWD:$PYTHONPATH)
--device cuda needs CUDA 이 PC에 CUDA가 없다 nvidia-smi --device를 빼고 CPU로 돌린다. 결과는 같다
worktree에서 고친 코드가 결과에 안 나온다 python scripts/x.py가 메인 트리의 패키지를 import했다 결과가 고치기 전과 같다 PYTHONPATH=$PWD:$PYTHONPATH를 붙여 돌린다

찾는 말이 이 주제에 없다. 모든 주제에서 찾기로 넓히거나 Esc로 지운다.
