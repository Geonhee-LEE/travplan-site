스터디 덱

개념과 수식을 고른 덱과, 논문 한 편씩을 다루는 덱입니다. PPTX는 슬라이드를 그림으로 넣은 판입니다.

travplan 리서치 스터디 — 보도 로봇을 움직이는 수식들

25장 · 발표자 노트 포함

  • 왜 costmap 대신 TravMap인가, 파이프라인 지도
  • 인식: 점군을 높이·비용·불확실성 지도로
  • Planner: diffusion과 flow matching으로 궤적을 생성
  • Controller: MPPI와 GP를 품은 NMPC
  • 안전: CVaR, CBF, conformal prediction
  • 결과, 공부 순서, 참고문헌

travplan 논문 스터디 — 챕터별 (편마다 세 장)

152장 · 발표자 노트 포함

  • 표지와 목차
  • 1장 인식: 지형 지도, traversability, 시각 기반 모델, 동적 장애물 예측
  • 2장 플래닝·고전/모델 기반: 그래프 탐색, 로컬 플래너, 궤적 최적화
  • 3장 플래닝·학습 기반: 명령형 학습, diffusion·flow 정책, VLA
  • 4장 제어·모델 기반: MPPI 계열과 GP-MPC
  • 5장 제어·학습 기반: 학습 동역학, 적응, world model, 보행 RL
  • 6장 안전: CBF, 도달 가능성, 예측 안전 필터, 위험 척도, conformal
  • 7장 시뮬레이션: 물리 엔진, 보도 시뮬레이터, sim-to-real
  • 정리와 참고문헌
