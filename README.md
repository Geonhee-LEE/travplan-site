# travplan 공개 사이트

**<https://geonhee-lee.github.io/travplan-site/>**

실외 보도 배달로봇(비동축 스워브)을 위한 2.5D traversability 기반 학습 Planner 연구 **travplan**의 공개 사이트다.

| 페이지 | 주소 |
|---|---|
| 첫 화면 | <https://geonhee-lee.github.io/travplan-site/> |
| 대시보드 (진행 현황, TODO, PRD, 리서치, 시뮬레이션 탭) | <https://geonhee-lee.github.io/travplan-site/dashboard.html> |
| Playground (브라우저 실시간 시뮬레이션) | <https://geonhee-lee.github.io/travplan-site/playground/> |
| Playground 사용법·구조·시연·검사 | [playground/README.md](playground/README.md) |

이 저장소는 연구 저장소(비공개)의 `docs/`를 GitHub Actions가 자동으로 복사한 것이다. 여기서 직접 고치면 다음 동기화가 덮어쓴다.
페이지 안의 이슈·PR 번호와 원본 문서 이름은 연구 저장소의 것이라 링크 없이 글자로 보인다.
복사본은 올리기 전에 위생 검사(로컬 경로·이메일·토큰 모양·비공개 저장소 링크)를 거친다.
